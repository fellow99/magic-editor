# 001-editor-core 测试用例

> 模块编号：001-editor-core
> 关联规范：[spec.md](./spec.md) / [plan.md](./plan.md)
> 对应源码：`src/components/editor/magic-script-editor.vue`
> 用例编号格式：`TC-001-NNN`
> 优先级：P0 = 阻断主流程，P1 = 关键功能，P2 = 增强/边界

---

## 1. 测试范围

**纳入**：Tab 管理、monaco 编辑器初始化、快捷键、断点设置、实时语法校验、脚本保存（API/Function）、脚本测试（含路径变量、文件上传、RequestBody）、调试会话（断点命中/继续/单步）、历史记录入口、脚本切换状态恢复。

**排除**：
- monaco 语言服务（语法高亮/补全/Hover）→ 见 012 模块测试
- 参数/Header 编辑表单 UI → 见 008 模块测试
- 历史记录 diff 渲染 → 见 002 模块测试
- 调试变量面板渲染 → 见 009 模块测试

## 2. 环境前置

| 项 | 期望 |
|---|---|
| 后端 | magic-api 服务可访问（baseURL 与 serverURL 已配置） |
| 鉴权 | 已登录，`HEADER_MAGIC_TOKEN_VALUE` 已写入 |
| 资源树 | `apiList` / `functionList` 已加载完成 |
| 浏览器 | 现代浏览器，支持 monaco-editor 0.29.x，localStorage 可写 |

## 3. 功能测试用例

### US-001 打开脚本进行编辑

#### TC-001-001 从资源树打开 API 脚本（首次打开）
- **关联**：FR-001、FR-009、US-001
- **优先级**：P0
- **前置**：资源树存在某接口 `A`
- **步骤**：
  1. 在资源树中单击接口 `A`
  2. 触发 `bus.$emit('open', A)`
- **预期**：
  - Tab 栏新增 `A` 标签且处于选中状态
  - monaco 加载 `A.script` 内容
  - `recent_opened_tab` 写入 localStorage 包含 `A.id`
  - 触发 `bus.$emit('opened', A)` 事件
- **备注**：观察 Network 请求，未保存过的脚本不应再次远程拉取

#### TC-001-002 重复打开同一脚本仅激活已有 Tab
- **关联**：FR-001、FR-002
- **优先级**：P1
- **前置**：脚本 `A` 已打开
- **步骤**：再次从资源树点击 `A`
- **预期**：Tab 数量不变，`A` 标签被激活；编辑器内容、断点、滚动位置保持不变

#### TC-001-003 同名脚本显示分组路径前缀
- **关联**：FR-010
- **优先级**：P2
- **前置**：分组 `g1`、`g2` 各有一个名为 `query` 的接口
- **步骤**：依次打开 `g1/query` 与 `g2/query`
- **预期**：两个 Tab 标签分别显示 `g1/query`、`g2/query`，可视区分

#### TC-001-004 新建脚本（无 ID）显示未保存标记
- **关联**：FR-003
- **优先级**：P0
- **步骤**：通过资源树"新增接口"创建空脚本并打开
- **预期**：Tab 标签后缀显示 `*`；`tmpScript === null`

### US-002 编辑脚本并实时校验

#### TC-001-010 合法脚本不显示标记
- **关联**：FR-040、FR-041、FR-042
- **优先级**：P0
- **步骤**：在编辑器中输入合法 magic-script，例如 `return 1;`
- **预期**：500ms 后 `monaco.editor.setModelMarkers` 调用结果为空数组；编辑器无红色波浪线

#### TC-001-011 非法脚本显示语法错误标记
- **关联**：FR-043
- **优先级**：P0
- **步骤**：输入残缺脚本，如 `return ;` 或 `if(`
- **预期**：500ms 后错误位置出现红色下划线，hover 显示 ParseException 消息

#### TC-001-012 连续输入应防抖（不应触发多次解析）
- **关联**：FR-040、NFR-001
- **优先级**：P2
- **步骤**：在 500ms 内连续输入 5 次字符
- **预期**：仅最后一次输入后触发一次校验（可在 Parser 处打断点验证）

#### TC-001-013 修正错误后标记应被清除
- **关联**：FR-042
- **优先级**：P1
- **步骤**：先输入非法脚本看到错误标记，再修正为合法语法
- **预期**：500ms 后红色波浪线消失

### US-003 保存脚本

#### TC-001-020 Ctrl+S 保存 API 类型脚本（首次保存）
- **关联**：FR-050、FR-051、FR-055、FR-057、US-003
- **优先级**：P0
- **前置**：API 类型新增脚本（无 id）已打开并编辑
- **步骤**：按 `Ctrl+S`
- **预期**：
  - 触发 `POST /save`，请求体不含 ext/groupName/_type 等内部字段
  - 响应携带新 id，写回 `info.id`
  - Tab 标签 `*` 消失
  - 状态条显示 `groupName/name(groupPath/path)`
  - 触发 `bus.$emit('report', 'script_add')`

#### TC-001-021 Ctrl+S 保存 Function 类型脚本
- **关联**：FR-050、FR-052、FR-056
- **优先级**：P0
- **前置**：Function 类型新增脚本已打开
- **步骤**：按 `Ctrl+S`
- **预期**：调用 `POST /function/save`；触发埋点 `function_add`

#### TC-001-022 已保存脚本再次保存触发更新埋点
- **关联**：FR-056
- **优先级**：P1
- **前置**：已存在 id 的 API 脚本
- **步骤**：修改后保存
- **预期**：触发埋点 `script_save`（非 `script_add`）

#### TC-001-023 保存时空 name 的 parameters 被剔除
- **关联**：FR-054
- **优先级**：P1
- **前置**：API 脚本，parameters 包含一行 `{name: '', value: 'x'}`
- **步骤**：保存
- **预期**：请求体 parameters 数组中不包含该空 name 项

#### TC-001-024 persistenceResponseBody=false 时保存剔除 responseBody
- **关联**：FR-058
- **优先级**：P2
- **前置**：`contants.config.persistenceResponseBody = false`
- **步骤**：保存包含 responseBody 内容的脚本
- **预期**：请求体 JSON 不含 `responseBody` 与 `responseBodyDefinition` 字段

#### TC-001-025 锁定脚本仍可保存（仅自动保存被跳过）
- **关联**：FR-062
- **优先级**：P2
- **前置**：`info.lock === '1'`
- **步骤**：手动按 Ctrl+S
- **预期**：保存请求正常发出（注意：测试时的自动保存会被跳过，见 TC-001-031）

### US-004 测试脚本

#### TC-001-030 Ctrl+Q 触发 API 测试（无路径变量）
- **关联**：FR-060、FR-061、FR-067、FR-070、US-004
- **优先级**：P0
- **前置**：API 脚本已保存，URL 不含 `{}` 占位
- **步骤**：按 `Ctrl+Q`
- **预期**：
  - 切换到请求面板（`switch-tab='request'`）
  - 实际 HTTP 请求携带 `Magic-Request-Session` 与 `magic-token` Header
  - 响应到达后切换到结果面板（`switch-tab='result'`）
  - 触发 `update-response-body` 或 `update-response-blob`
  - 状态条更新耗时/状态码/响应大小

#### TC-001-031 AUTO_SAVE=true 时测试前自动保存
- **关联**：FR-062、NFR-008
- **优先级**：P1
- **前置**：`contants.AUTO_SAVE=true`，脚本未锁定，存在未保存修改
- **步骤**：按 Ctrl+Q
- **预期**：先发起一次保存请求，再发起测试请求

#### TC-001-032 锁定脚本测试时不自动保存
- **关联**：FR-062
- **优先级**：P1
- **前置**：`info.lock === '1'`，AUTO_SAVE=true
- **步骤**：按 Ctrl+Q
- **预期**：仅发出测试请求，无保存请求

#### TC-001-033 路径变量替换（接口级 + 分组级）
- **关联**：FR-063
- **优先级**：P0
- **前置**：URL 为 `/user/{id}/group/{gid}`，接口 paths 含 `{name:id, value:1}`，分组级 paths 含 `{name:gid, value:99}`
- **步骤**：执行测试
- **预期**：请求 URL 为 `/user/1/group/99`

#### TC-001-034 路径变量未填写时阻止测试
- **关联**：FR-064
- **优先级**：P0
- **前置**：URL 含 `{id}`，paths 未提供 `id`
- **步骤**：执行测试
- **预期**：弹出"请填写路径变量后在测试！"，无 HTTP 请求发出

#### TC-001-035 文件上传参数转 FormData
- **关联**：FR-065
- **优先级**：P0
- **前置**：parameters 含一项 `dataType=FileList, value=[File1, File2]`
- **步骤**：执行测试
- **预期**：请求 `Content-Type` 为 `multipart/form-data`；请求体为 FormData 含两个文件

#### TC-001-036 RequestBody 为合法 JSON 时使用 application/json
- **关联**：FR-066
- **优先级**：P0
- **前置**：`info.requestBody = '{"a":1}'`
- **步骤**：执行测试
- **预期**：请求 `Content-Type: application/json`；请求体为 `{"a":1}` 字符串

#### TC-001-037 RequestBody 非 JSON 时回退普通参数模式
- **关联**：FR-066
- **优先级**：P1
- **前置**：`info.requestBody = 'plain text'`
- **步骤**：执行测试
- **预期**：不设置 application/json；不将 requestBody 作为请求体（按普通参数处理）

#### TC-001-038 全局参数与全局 Header 自动注入
- **关联**：FR-069
- **优先级**：P1
- **前置**：localStorage 中 `global-parameters=[{name:'token',value:'t1'}]`，`global-headers=[{name:'X-Env',value:'dev'}]`
- **步骤**：执行测试
- **预期**：实际请求 query 含 `token=t1`，Header 含 `X-Env: dev`

#### TC-001-039 断点行号通过 Header 发送
- **关联**：FR-068
- **优先级**：P0
- **前置**：脚本第 3、7 行已设置断点

#### TC-001-040 文件下载响应转 blob
- **关联**：FR-071、FR-072
- **优先级**：P1
- **前置**：被测接口返回 `Content-Disposition: attachment` + 二进制

#### TC-001-041 未打开任何脚本时测试操作给出提示

#### TC-001-042 Function 类型不可测试

### US-006 调试会话
