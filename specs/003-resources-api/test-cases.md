# 003-resources-api 测试用例

> 模块编号：003-resources-api
> 关联规范：[spec.md](./spec.md)
> 对应源码：`src/components/resources/magic-api-list.vue`、`magic-resource.css`
> 用例编号格式：`TC-003-NNN`
> 优先级：P0 = 阻断主流程，P1 = 关键功能，P2 = 增强/边界

---

## 1. 测试范围

**纳入**：
- 资源树加载与渲染（分组+接口合并、缩进、默认展开）
- 关键字搜索过滤
- 接口/分组的 CRUD（新建、修改、删除）
- 同组复制、跨组复制、分组复制
- 拖拽移动接口与分组（含循环引用校验）
- 锁定/解锁接口
- 路径复制（绝对/相对）
- 分组导出 zip
- 排序与折叠/展开
- 右键菜单
- Alt+G 快捷键
- bus 事件订阅与发射
- JavaClass API 发现器注册

**排除**：
- 接口脚本编辑（001 模块）
- 分组选择对话框 MagicGroupChoose 内部行为（006 模块）
- 树通用组件 MagicTree 内部细节（016 模块）
- 编辑器 tab 关闭副作用的具体实现（001 模块）

---

## 2. 环境前置

| 项 | 期望 |
|---|---|
| 后端 | magic-api 可访问，`group/list?type=1`、`list` 等端点可用 |
| 全局 | `bus`、`contants.SERVER_URL`、`contants.DEFAULT_EXPAND` 已配置 |
| 数据 | 至少存在 1 个分组与若干接口，1 个嵌套分组用于拖拽测试 |
| 通用组件 | MagicTree、MagicDialog、MagicInput、`$magicContextmenu` 已注册 |
| 浏览器 | 支持 `document.execCommand('copy')` 与拖拽 API |

## 4. 边界与异常

| 编号 | 场景 | 预期 |
|---|---|---|
| TC-003-200 | `lock` 字段为字符串 `'1'` 而非布尔 | 仍正确显示锁图标（AS 假设 2） |
| TC-003-201 | 分组 `parentId='0'` 视为根分组 | 正确放置在根级 |
| TC-003-202 | 接口 `method` 字段为空 | MagicTextIcon 渲染兜底（C-003-001 待澄清） |
| TC-003-203 | 同 ID 分组重复 | `pushFileItemToGroup` 命中第一个（C-003-002 待澄清） |
| TC-003-204 | 快速连续 `position-api` 请求 | 可能竞态，后到响应覆盖（C-003-003 待澄清） |
| TC-003-205 | 网络失败时 group/create | 树未新增，错误提示 |
| TC-003-206 | 删除接口已被后端删除 | 后端 4xx；前端仍移除节点并关闭 tab（确认现状） |
| TC-003-207 | 拖拽过程被 ESC 中断 | 不发请求，无视觉残留 |
| TC-003-208 | 搜索关键字含正则元字符（`*`、`(`）| 视为字面量匹配，不抛异常 |
| TC-003-209 | 复制接口名已含"(复制)" | 追加变成 `名(复制)(复制)` |
| TC-003-210 | 导出失败（5xx） | 不下载，提示错误 |
