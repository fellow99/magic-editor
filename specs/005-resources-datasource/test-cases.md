# 005-resources-datasource 测试用例

> 模块编号：005-resources-datasource
> 关联规范：[spec.md](./spec.md)
> 对应源码：`src/components/resources/magic-datasource-list.vue`
> 用例编号格式：`TC-005-NNN`
> 优先级：P0/P1/P2

---

## 1. 测试范围

**纳入**：数据源列表渲染、关键字搜索、新建/编辑对话框、表单校验、JSON 扩展配置合并、测试连接、保存、删除、SQLModule 补全注册、bus 事件订阅、loading/空状态。

**排除**：后端连接池实现、密码加密、SQLModule 在补全中的渲染（属 012-script-language）。

---

## 2. 环境前置

| 项 | 期望 |
|---|---|
| 后端 | `datasource/list`、`datasource/detail`、`datasource/save`、`datasource/test`、`datasource/delete` 可访问 |
| 数据 | 至少 1 个含 id 的数据源 + 1 个无 id 的"主数据源"（可选） |
| 全局 | bus、`JavaClass`、monaco-editor、`store` 已就绪；`contants.JDBC_DRIVERS`、`DATASOURCE_TYPES` 已注入 |

---

## 3. 功能用例

### US-001 浏览数据源列表

#### TC-005-001 列表渲染显示名称与 key
- **关联**：FR-005-001
- **优先级**：P0
- **预期**：每项显示名称（默认"主数据源"）和 key（默认"default"）

#### TC-005-002 加载中显示 loading
- **关联**：FR-005-002、NFR-005-003、NFR-005-005
- **优先级**：P1
- **预期**：请求期间显示"加载中..."，完成后延迟 500ms 隐藏

#### TC-005-003 空列表显示无数据
- **关联**：FR-005-003
- **优先级**：P1
- **预期**：`datasources.length===0` 时显示"无数据"

#### TC-005-004 刷新按钮重新拉取
- **关联**：FR-005-007
- **优先级**：P1
- **预期**：点击 → `POST datasource/list`

## 4. 边界与异常

| 编号 | 场景 | 预期 |
|---|---|---|
| TC-005-200 | 其它配置为非法 JSON | 保存前提示并阻止 |
| TC-005-201 | 编辑模式密码为空（NC-002） | 行为待澄清，不应静默清空 |
| TC-005-202 | 同 key 重复创建 | 后端返回错误，前端提示 |
| TC-005-203 | maxRows 输入非数字 | 后端校验或前端类型限制 |
| TC-005-204 | 网络异常时测试连接 | 显示网络错误而非"连接成功" |
| TC-005-205 | monaco 在对话框关闭后内存释放 | `editor.dispose()` 调用 |
| TC-005-206 | 切换主题后再打开对话框 | monaco 主题与 `store.get('skin')` 一致 |
| TC-005-207 | 列表中含 100+ 数据源搜索性能 | 输入响应 < 100ms |
