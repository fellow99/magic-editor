## 1. 测试范围

**纳入**：顶部工具栏（运行/保存/搜索/历史/上传/导出/推送/换肤/刷新）、状态栏（消息、外链、用户）、登录覆盖层、bus 事件契约、HTTP 端点交互。

**排除**：HTTP 拦截实现（014）、bus/store 实现（015）、底部 Options（010）、全局搜索内部、资源选择器内部（006）。

## 4. 边界与异常

| 编号 | 场景 | 预期 |
|---|---|---|
| TC-007-200 | 未打开任何资源 | info.empty=true，路径区为空 |
| TC-007-201 | 上传超大 ZIP | 后端响应错误时 status 显示失败 |
| TC-007-202 | 推送目标地址非法 | 后端 4xx → status 显示错误 |
| TC-007-203 | 网络断开时点击保存 | 仅 emit doSave，由编辑器处理失败 |
| TC-007-204 | localStorage 无 skin 键 | 使用 `config.defaultTheme` |
| TC-007-205 | Themes 为空 | 换肤下拉无选项 |
| TC-007-206 | 状态栏 user 未加载 | 用户区不显示 |
| TC-007-207 | 连续 401 多次 | 仅显示一次登录弹窗（防重复） |
| TC-007-208 | 推送秘钥默认 123456789（Q-002） | 安全风险待澄清 |
