### E2E 运行完整链路

#### TC-008-220 API 创建→SQL 编写→运行→保存→刷新→再运行
- **关联**：FR-007-004、FR-007-041、FR-008-002、FR-008-040、FR-101-RES-04
- **优先级**：P0
- **前置**：接口树中已有分组；后端 magic-api 2.2.2 运行中
- **步骤**：
  1. 右键接口分组 → "新建接口" → 名称 `sql_test`、路径 `/sql_test`
  2. 底部"接口信息"面板切换到"请求 Body"子页签
  3. 在 Monaco 编辑器中输入：`select 'a' as val1`
  4. 点击顶部工具条"运行（Ctrl+Q）"
  5. 检查底部"执行结果"面板：显示运行响应内容
  6. 点击顶部工具条"保存（Ctrl+S）"
  7. 检查网络：`POST /resource/file/api/save` 调用成功
  8. 检查数据文件：`/tmp/magic-api-data/api/<group>/sql_test.ms` 包含 `select 'a' as val1`
  9. 刷新浏览器页面
  10. 验证接口树中 `sql_test` 存在且可点击加载
  11. 验证编辑器加载后显示 `select 'a' as val1`
  12. 再次点击"运行（Ctrl+Q）"
  13. 验证"执行结果"面板再次显示正确运行结果
- **预期**：完整 13 步链路无异常；数据持久化正确；运行功能在刷新前后均可用

#### TC-008-221 运行后未保存状态下刷新数据不丢失验证
- **关联**：FR-007-041、FR-008-002
- **优先级**：P1
- **前置**：已打开一个已有接口并修改了脚本内容
- **步骤**：
  1. 修改编辑器内容但不保存（Tab 显示 `*` 标记）
  2. 点击"运行（Ctrl+Q）"
  3. 验证运行使用的是当前编辑器中的最新内容
  4. 刷新浏览器页面
  5. 重新打开该接口
  6. 验证内容为上次保存的版本（非刷新前未保存的修改）
- **预期**：运行使用最新编辑内容；未保存的修改刷新后丢失（符合预期行为）

#### TC-008-222 保存后刷新编辑器脚本内容恢复验证

## 4. 边界与异常

| 编号 | 场景 | 预期 |
|---|---|---|
| TC-008-200 | Body 编辑器粘贴非法 JSON | 不抛错，仅停止格式化 |

| TC-008-202 | 响应 contentType=image/png 含 disposition | 自动下载，不显示 iframe |
| TC-008-203 | ws_log 高频推送（每 10ms 一条） | 自动滚动不卡死 |

| TC-008-206 | /options 加载失败 | 下拉无候选，仍可手输 |
| TC-008-207 | 分组保存失败（4xx） | status 文案"失败" |
| TC-008-208 | 路径变量与请求参数同名 | 测试调用由 001 决定优先级 |
| TC-008-209 | 删除唯一参数行 | 自动补空行（FR-038） |
| TC-008-210 | window 高度小于 150px | 拖拽下限锁定 |
| TC-008-211 | 二进制响应无 disposition | iframe 渲染（不下载） |
| TC-008-212 | response code=1000（断点） | 切换到 Debug Tab，变量入表 |
| TC-008-213 | response code=-1000（脚本错误） | Body 显示错误信息 |
